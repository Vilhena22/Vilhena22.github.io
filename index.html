kubeApp/

Kubernetes/K3s cluster manager · Java desktop app

A graphical interface for managing a Kubernetes/K3s cluster through the official Kubernetes API, covering the operations you would otherwise run with kubectl. A dashboard shows live CPU and RAM usage from Prometheus. You can list, create, and delete nodes, namespaces, pods, deployments, and services, with inline validation and clear error messages.

It includes an AI assistant built with LangChain4j and a local LLM (Ollama) that answers questions about cluster and node status by calling tools against the live cluster. Previously used clusters are saved locally in SQLite for quick reconnection.

Java 21 Kubernetes K3s Prometheus PromQL LangChain4j Ollama Swing/JavaFX SQLite Maven

homelab/

Virtualisation and self-hosting with Proxmox VE · personal project (no public repo)

An infrastructure laboratory I designed, built, and administer on repurposed hardware, running on Proxmox VE. It hosts virtual machines, storage, and multiple self-hosted services.

The network is segmented, with DNS, traffic filtering, and a VPN for secure remote access. A reverse proxy with centralised certificate management fronts the internal services. I also run databases to support applications, and handle day-to-day Linux administration: maintenance, updates, configuration, and troubleshooting.

Proxmox VE Virtualisation Linux Networking DNS VPN Reverse proxy Certificates Databases
